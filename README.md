# Squad Comms

Голосовой + текстовый канал в браузере на 5 человек. Без установки клиента,
без Discord/TeamSpeak, без платного хостинга.

## Как это работает

- Звук идёт напрямую между браузерами (P2P, WebRTC), сервер только "знакомит"
  участников между собой (сигналинг) и разносит текстовые сообщения.
- Максимум 5 человек в одном канале — задаётся в `server.js`
  (`MAX_PER_ROOM`), можно поднять, но для mesh-топологии больше 5-6 человек
  начинает нагружать канал каждого участника.

## Запуск локально

```bash
npm install
npm start
```

Открой `http://localhost:3000` в нескольких вкладках/устройствах в одной сети.

## Бесплатный деплой (чтобы работало для всех, не только в локальной сети)

Проще всего — **Render.com**, бесплатный тариф без карты:

1. Залей этот проект на GitHub (публичный или приватный репозиторий).
2. На render.com → New → Web Service → выбери репозиторий.
3. Build command: `npm install`
4. Start command: `npm start`
5. Environment: Node. Регион — любой, ближе к тебе.
6. Деплой. Получишь ссылку вида `https://squad-comms.onrender.com`.

Альтернативы с похожим бесплатным тиром: **Fly.io**, **Railway** (лимит часов
в бесплатном тарифе), **Cyclic.sh**.

Бесплатный тир Render "засыпает" после ~15 минут без обращений и просыпается
секунд за 20-30 при следующем заходе — для созвона перед игрой это не проблема,
просто открой ссылку немного заранее.

## Важный нюанс сети — прочитай перед тем как ругаться, что "не подключается"

WebRTC пробивает NAT сам, используя STUN-сервер (в коде — публичный от Google,
бесплатно). Это работает почти всегда, **кроме** случая, когда у одного из
участников **CGNAT** (Carrier-Grade NAT) — это когда провайдер не даёт
отдельный публичный IP, а прячет несколько клиентов за одним адресом.
Часто встречается у мобильных операторов и у части домашних провайдеров РФ.

Если у кого-то в отряде именно такой провайдер, чистый P2P (STUN) может не
пробиться, и понадобится **TURN-сервер** — он уже не бесплатный на постоянку
(проходящий через него трафик кто-то должен оплачивать). Бесплатный вариант
на попробовать: **metered.ca** (бесплатный TURN до 50 ГБ/мес) или поднять
свой **coturn** на том же бесплатном VPS, где крутится сигналинг-сервер.
Если 4 из 5 подключаются нормально, а один — нет, это почти наверняка тот
самый случай.
